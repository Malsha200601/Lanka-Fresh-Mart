1. Where CSS Grid Is Used

CSS Grid is used to arrange items in rows and columns.

In this project, it is used for:

* Displaying dashboard cards.
* Arranging charts side by side.
* Centering icons.

2. Where Flexbox Is Used

Flexbox is used to arrange and align items in a row or column.

In this project, it is used for:

* Arranging the sidebar and main content.
* Aligning navigation links.
* Arranging icons and text.
* Aligning the profile section.

3. Known Issues

Some common issues are:

* Items may not fit on small screens.
* Text may overflow.
* Cards may have different heights.
* Spacing may not look correct.
* Some layouts may look different in older browsers.

4. Conclusion

CSS Grid is used for rows and columns, while Flexbox is used for alignment and arranging items. Both help create a responsive and user-friendly dashboard.
